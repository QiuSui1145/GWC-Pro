========================================
  GWC 桌宠 MMD (3D) 模型放置说明
========================================

【怎么放】
在本文件夹（mmd_models）下，为每个模型建一个子文件夹，把该模型的
全部文件放进去。例如：

  mmd_models/
    ├─ 初音未来/
    │    ├─ miku.pmx          ← 模型主文件（.pmx 或 .pmd）
    │    ├─ tex/              ← 贴图文件夹（模型引用的贴图，保持原相对路径）
    │    │    └─ *.png / *.tga ...
    │    └─ 待机.vmd          ← （可选）动作文件，可放多个
    └─ 其他模型/
         └─ xxx.pmx

要点：
  1. 每个含 .pmx / .pmd 的文件夹会被识别为一个模型，文件夹名就是显示名。
  2. 贴图务必和 .pmx 里记录的相对路径一致（通常保持模型原始文件夹结构即可）。
  3. .vmd 动作文件（可选）放在模型文件夹里，会出现在设置的“动作”下拉中。
     骨骼物理（头发/裙摆摆动）会自动叠加在动作之上。

【怎么用】
  1. 放好模型后，（若后端已在运行）重启后端，或在桌宠设置里点“🔄 重新扫描”。
  2. 右键桌宠托盘 → 桌宠设置 → “🧊 MMD 3D 模型”：
       - 选择模型 → 自动加载并从 Live2D 切换到 3D；
       - 选择动作（.vmd）；
       - 渲染方式：三渲二（卡通描边）/ 写实（真实光照）；
       - 可勾选/取消“骨骼物理”。
  3. 拖动模型移动位置，滚轮缩放，托盘“桌宠复位”可复位。
  4. “↩️ 卸载 MMD，返回 Live2D” 切回 2D 模型。

【找不到模型？】
  - 确认文件夹里确有 .pmx / .pmd 文件；
  - 点“重新扫描”或重启后端；
  - 若模型显示但贴图发白/缺失，多半是贴图相对路径不对，检查 tex 文件夹结构。
